TÉCNICAS DE ASEGURAMIENTO
DE CALIDAD

Las técnicas de aseguramiento de la calidad permiten detectar defectos, prevenir errores y garantizar que el software cumpla con los requisitos establecidos.

✓

NIVELES DE PRUEBAS

/>

Pruebas unitarias

Verifican el funcionamiento correcto de unidades individuales de código.

✣

Pruebas de integración

Validan la interacción entre componentes y módulos.

⚙

Pruebas de sistema

Evalúan el sistema completo como un todo.

♟

Pruebas de aceptación

Confirman que el sistema cumple los requisitos del usuario final.

TIPOS DE PRUEBAS

Funcionales

Verifican que el sistema realice las funciones esperadas.
